# F-03 무거운 대화에서 시작하면 시작 맥락을 호출마다 다시 읽는 값이 크다
- 상태: 유효
- 갈래: 절차
- 세기: 관측 반복 (carry 2번, 워크로그 44번. 모델과 시기는 통제하지 않음)
- 확인: 2026-11-17
- 근거 1: `carry --session f4af52de --skill record-obsidian` → 시작 맥락 159,319 × 43번 = 6,850,717 (누적 입력의 66%). `carry --session 071d0c00 --skill record-obsidian` → 829,512 × 44번 = 36,498,528 (92%).
- 근거 2: collect-worklog. `stats --skill collect-worklog --since 2026-08-24 --session 15589b2d` → 오래 쓴 한 세션 21번, 시작 맥락 중앙값 572,040, 누적 입력 중앙값 8,455,804, 정가 환산 중앙값 $10.55 (합 $255.22). 같은 명령에 `--not-session 15589b2d` → 새 세션 23번, 시작 맥락 중앙값 61,608, 누적 입력 중앙값 2,498,356, 정가 환산 중앙값 $2.57 (합 $74.02).
- 사실: 같은 스킬도 시작 맥락이 크면 몇 배가 든다. 값으로 치면 시작 맥락을 다시 읽은 몫은 11-16 실행에서 6,850,717 × $0.20/백만 = $1.37 로 그 실행 $5.18 의 26%, 11-12 실행에서 36,498,528 × $0.20/백만 = $7.30 으로 $15.88 의 46%다.
- 한계: carry 는 두 실행만 봤다. 근거 2의 두 묶음은 모델과 시기가 다르다(오래 쓴 세션은 모두 opus-4-8, 새 세션은 네 모델이 섞임). 날마다 워크로그 양도 다르다. 스킬 본문을 고치는 것보다 큰지는 재지 않았다(D-01).
- 다시 볼 때: D-01 을 판정할 때
