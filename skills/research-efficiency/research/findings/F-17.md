# F-17 record-obsidian 을 나눈 뒤 본 대화 몫은 줄고 서브에이전트가 그보다 더 썼다
- 상태: 유효
- 갈래: 절차
- 세기: 전후 비교 (사전 16번, 사후 16번. 사후는 멈춘 실행 3번과 볼트 전체 검진 실행 1번을 뺐다. 모델 구성이 달라 기준 단가 환산으로 견줬다)
- 확인: 2026-11-26
- 근거 1: 사전 `stats --skill record-obsidian --until "2026-11-16 17:00"` → 16번(Opus 5.5 14, Sonnet 5.5 1, Fable 5.2 1), 기준 단가 환산 중앙값 $5.28, 누적 입력 중앙값 9,541,450, 본 대화 누적 입력 중앙값 9,541,450, 본 대화 호출 중앙값 27, 시작 맥락 중앙값 322,715, 서브 호출 중앙값 0.
- 근거 2: 사후 `stats --skill record-obsidian --since "2026-11-16 17:25" --not-session dec8375b f8e36187 --not-run "2026-11-18 11:51"` → 16번(Opus 5.5 13, Fable 5.2 3), 기준 단가 환산 중앙값 $8.11(최소 3.44, 최대 37.94), 누적 입력 중앙값 15,172,100, 본 대화 누적 입력 중앙값 2,602,577, 본 대화 호출 중앙값 11, 시작 맥락 중앙값 166,375, 서브 호출 중앙값 65, 서브 누적 입력 중앙값 13,048,085, 서브 출력 중앙값 62,020. 뺀 것: 세션 dec8375b, f8e36187 은 본 대화 호출 1~2번에 서브에이전트가 없는 멈춘 실행이고, 4938114c 의 11-18 11:51 실행은 볼트 전체 검진이다. 같은 세션의 11-24 실행은 넣었다.
- 근거 3: 시작 맥락 12만 아래만. 사전 `--ctx-below 120000` 4번 기준 단가 환산 중앙값 $2.77, 사후 같은 조건 4번 $8.38.
- 사실: 나눈 뒤 본 대화 누적 입력 중앙값은 사전의 27%(2,602,577 ÷ 9,541,450)로, 본 대화 호출 중앙값은 27 에서 11 로 줄었다. 그러나 서브에이전트 누적 입력 중앙값이 13,048,085 여서 실행 전체 누적 입력 중앙값은 1.59배(15,172,100 ÷ 9,541,450), 기준 단가 환산 중앙값은 1.54배(8.11 ÷ 5.28)가 됐다. 시작 맥락 12만 아래 실행끼리는 3.03배(8.38 ÷ 2.77)다.
- 한계: 같은 날 볼트 record 노트를 LLM 전용 형식으로 바꿨고, 그 뒤 record 노트와 기록 규칙이 계속 늘어 사후 실행의 읽기 범위가 사전보다 넓을 수 있다. 실행마다 주제와 고친 노트 수가 달라 구조 탓과 작업 범위 탓을 가르지 못한다. 품질은 앞 5번의 사후 정정 요청만 셌다(A-01).
