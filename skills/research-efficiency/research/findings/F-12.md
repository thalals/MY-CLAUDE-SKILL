# F-12 공식 문서의 근거 문장
- 상태: 유효
- 갈래: 지시
- 세기: 문서
- 확인: 2026-11-16 (code.claude.com/docs/en/costs, /skills, /statusline, platform.claude.com/docs/en/about-claude/pricing)
- 근거: 공식 문서 원문(아래 줄). 명령으로 다시 낼 수 없고 문서를 다시 읽어 확인한다.
- 사실: 공식 문서는 맥락 크기가 비용을 정하고, 스킬 본문은 실린 뒤 매 호출 다시 읽히며, 포크는 대화 기록을 보지 못한다고 적는다. 아래가 그 원문이다.
- 비용: "Token costs scale with context size … Stale context wastes tokens on every subsequent message."
- 비용: "Delegate these to subagents so the verbose output stays in the subagent's context while only a summary returns to your main conversation."
- 스킬: "Once a skill loads, its content stays in context across turns, so every line is a recurring token cost."
- 스킬, 압축 뒤: "keeping the first 5,000 tokens of each"
- 스킬, context: fork: "The subagent doesn't see your conversation history"
- 스킬, disable-model-invocation: true: "Description not in context, full skill loads when invoked"
- 스킬, 부를 때 명령 실행(2026-11-17 확인): "The `` !`<command>` `` syntax runs shell commands before the skill content is sent to Claude. The command output replaces the placeholder, so Claude receives actual data, not the command itself."
- 스킬, 본문 길이(2026-11-17 확인): "Keep `SKILL.md` under 500 lines. Move detailed reference material to separate files."
- 한계: 문서는 바뀐다. 근거로 다시 쓸 때는 원문을 다시 확인한다.
- 다시 볼 때: 근거로 다시 쓸 때 원문을 다시 확인한다
