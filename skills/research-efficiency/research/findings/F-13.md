# F-13 세션 원본은 기본 30일 뒤 서브에이전트 원본과 함께 지워진다
- 상태: 유효
- 갈래: 측정
- 세기: 문서
- 확인: 2026-11-17 (code.claude.com/docs/en/data-usage, /claude-directory)
- 근거: 공식 문서 원문(아래). 사용자 설정에 cleanupPeriodDays 가 없다(2026-11-17, 설정 파일의 그 키만 봤다). `~/.claude/projects` 는 871MB 였다(2026-11-17, du). 2026-11-16 에 가장 오래된 원본은 28일 전 것이었다.
- 원문, 보존: "Claude Code clients store session transcripts locally in plaintext under `~/.claude/projects/` for 30 days by default to enable session resumption. Adjust the period with `cleanupPeriodDays`."
- 원문, 범위: "The default is 30 days and the minimum is 1; setting `0` fails with a validation error."
- 원문, 서브에이전트: "Subagent transcripts in the same format as the session transcript, removed with the parent session transcript when it ages out."
- 사실: 장부에 남는 측정은 원본이 지워지기 전에 `runs --save` 로 옮긴 숫자뿐이다. 회차 사이가 30일을 넘으면 그 사이의 실행은 다시 잴 수 없고, 지표 정의를 바꿔도 30일보다 오래된 실행은 새 정의로 다시 낼 수 없다.
- 한계: 문서는 바뀐다. 실제로 지워진 시점은 재지 않았다. 원본에 남는 것은 실행 단위 숫자라 서브에이전트마다의 숫자는 runs.tsv 에 없다.
- 다시 볼 때: 보존 설정을 바꿀 때와 runs.tsv 의 30일보다 오래된 줄을 다시 재려 할 때
