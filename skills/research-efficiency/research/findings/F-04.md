# F-04 쉬었다가 이어 하면 첫 호출이 대화 전체를 캐시에 다시 쓴다
- 상태: 유효
- 갈래: 절차
- 세기: 관측 반복 (옛 구조 기록 16번)
- 확인: 2026-11-17
- 근거: runs.tsv 의 first_write 열(`runs --session ID --skill record-obsidian` 의 '첫 호출 캐시 쓰기'). record-obsidian 옛 구조 16번 가운데 6번이 10만 이상이다. 11-12 는 802,193(시작 맥락 829,512), 11-11 16:30 은 494,447, 11-10 18:25 는 413,577, 11-13 은 345,911, 11-05 17:55 는 333,640, 11-16 은 132,000. 1시간 캐시 쓰기 정가($8/백만)를 곱하면 11-12 는 $6.42(그 실행 $15.88 의 40%), 11-13 은 $2.77($6.73 의 41%), 11-16 은 $1.06($5.18 의 20%).
- 사실: 캐시가 식은 뒤의 첫 호출은 그때 맥락의 대부분을 입력 단가의 2배로 다시 쓴다.
- 한계: 본 대화 캐시 수명 1시간은 원본의 쓰기 종류(1h)로 본 것이다. 얼마나 쉬면 식는지는 실행마다 재지 않았다.
- 다시 볼 때: 본 대화의 캐시 쓰기 종류가 1시간이 아닌 실행이 보일 때
