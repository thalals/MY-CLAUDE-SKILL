# D-17 임시 스크립트로 낸 값은 도구로 옮겨 대조한 뒤에 장부에 쓴다
- 상태: 후보 (2026-11-18)
- 갈래: 연구실
- 대상: 이 스킬 본문 '지키는 것' 의 임시 스크립트 항
- 근거: F-16 의 새 단계 사본 회차(세션 2790a889)가 회차 기록에, 임시 스크립트로 낸 값 하나가 같은 측정을 도구 명령으로 옮긴 값과 달라 도구 값으로 고쳤다고 적었다. 사본 장부의 값이라 수치는 옮기지 않는다. 지금 본문은 다시 쓸 측정만 도구의 명령으로 옮기게 해서, 한 번 쓰는 측정은 대조 없이 장부에 들어간다.
- 방법: '지키는 것' 의 임시 스크립트 항을 '임시 스크립트로 낸 값은 장부에 쓰기 전에 도구의 명령으로 옮기고 두 값을 대조한다. 다르면 도구 값을 쓴다' 로 바꾼다.
- 예상: 임시 스크립트의 틀린 값이 장부에 들어가는 것을 막는다. 회차마다 도구 코드를 옮기는 값이 는다(그 사본 회차에서는 도구 코드 115줄, diff 로 셈).
- 틀렸다고 볼 기준: 규칙을 넣은 뒤 5회차 가운데 옮겨서 값이 달라진 회차가 0번이면 규칙을 뺀다(회차 기록의 learned 에서 센다).
- 품질 위험: 한 번만 쓸 측정에도 도구 코드가 늘어 도구가 커진다.
